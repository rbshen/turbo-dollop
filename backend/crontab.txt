# Fathom cron schedule. Install with: crontab crontab.txt
# (This replaces the whole crontab for this user -- merge by hand with
# `crontab -e` if other jobs already exist outside this project.)
#
# To change either schedule, edit the "minute hour" fields below -- nothing
# in the scripts themselves needs touching for a schedule change.

# ---------------------------------------------------------------------------
# Nightly chain, 12:00-12:40 AM then 2:45-3:30 AM server time (UTC); technical
# jobs moved from 2:00-2:40 to 12:00-12:40 on 2026-10-01. Order reordered 2026-09-30:
# technical jobs first, fundamentals later (technical data is the higher
# priority). Order, each job in its own slot:
#   last close -> Weinstein + bar-cache fill -> Liquidity Zone (support/resistance)
#   -> BB+RSI -> Warren -> Sector ETF heatmap -> Market Breadth
#   -> corporate events -> FMP fundamentals -> analyst price-target
#   -> score recompute -> SQLite backup
# Hard ordering constraints (pinned by tests/test_cron_wiring.py):
#   * the Weinstein/bar-cache job (pipeline.nightly_trend_calculation -- the "trend" name is
#     historical) fills the shared daily-bar cache; LP, Sector and Breadth read it warm
#   * BB+RSI before Warren (BB+RSI creates the 60d intraday row, Warren widens it)
#   * score recompute after Weinstein/BB+RSI/Warren, and before the backup
# Everything else is preference. Windows below are sized from observed CronRunLog
# durations; if a job is moved, keep its successor's slot at least as far out.
# Every command uses `-m package.module` (NOT a direct script path) run from
# backend/ via the `cd`: these scripts live in subpackages and import siblings
# with absolute-from-backend paths, which only resolve when backend/ is on
# sys.path. `python pipeline/foo.py` puts pipeline/ there instead and fails
# with ModuleNotFoundError.
# ---------------------------------------------------------------------------

# 12:00 Last official close per ticker (FMP /historical-price-eod/full, one call
# per tracked US ticker, ~1-1.5 min paced) -- the ticker header's price fallback
# when the live FMP quote is unavailable. Independent of the shared bars cache,
# so it has no ordering constraint and goes first. Skipped (a real `skipped` cron
# status) while `daily_prices` is off. See pipeline/nightly_last_close_snapshot.py.
0 0 * * * cd /home/shen/fathom/backend && /home/shen/.local/bin/uv run python -m pipeline.nightly_last_close_snapshot >> /home/shen/fathom/backend/logs/nightly_last_close_snapshot_cron.log 2>&1

# 12:05 Weinstein stage calculation + daily-bar cache fill (the job's "trend" name is
# historical; the swing/BOS trend-structure calculation was removed).
# Reads FMP daily bars (data group daily_prices) through the shared bars cache and
# is the ONLY job that fills the daily-bar cache -- LP, Sector and Breadth below
# read it warm. 10-minute window (typical 1-3 min, max seen ~6 min). Reports a
# real `skipped` status while daily_prices is off. See pipeline/nightly_trend_calculation.py.
5 0 * * * cd /home/shen/fathom/backend && /home/shen/.local/bin/uv run python -m pipeline.nightly_trend_calculation >> /home/shen/fathom/backend/logs/nightly_trend_calculation_cron.log 2>&1

# 12:15 Liquidity Zone (LP, support/resistance) detection recompute. Scoped to the
# monitored-watchlist union only (E<number> and ETF lists). Reads daily bars through the
# shared bars cache (the same "1d" rows the 12:05 bar-cache job fills; skipped while
# daily_prices is off). ~10s.
# See pipeline/nightly_liquidity_zone_calculation.py.
15 0 * * * cd /home/shen/fathom/backend && /home/shen/.local/bin/uv run python -m pipeline.nightly_liquidity_zone_calculation >> /home/shen/fathom/backend/logs/nightly_liquidity_zone_calculation_cron.log 2>&1

# 12:20 BB+RSI (2h) technical entry-signal calculation. Scoped to the monitored
# watchlist union (E<number> and ETF lists). Reads FMP 60m bars (data group
# intraday_bars) through the shared bars cache; real `skipped` status while that group is off. Must run
# BEFORE Warren (BB+RSI creates the 60d row, Warren widens it to 2y). 5-minute
# window (typical 10-40s, max seen ~130s). See pipeline/nightly_entry_signal_calculation.py.
20 0 * * * cd /home/shen/fathom/backend && /home/shen/.local/bin/uv run python -m pipeline.nightly_entry_signal_calculation >> /home/shen/fathom/backend/logs/nightly_entry_signal_calculation_cron.log 2>&1

# 12:25 Warren RSI/ADX/WVF (2h) entry-signal calculation. Same monitored-watchlist scoping, but

# See pipeline/nightly_warren_signal_calculation.py and docs/specs/warren-signal.md.
25 0 * * * cd /home/shen/fathom/backend && /home/shen/.local/bin/uv run python -m pipeline.nightly_warren_signal_calculation >> /home/shen/fathom/backend/logs/nightly_warren_signal_calculation_cron.log 2>&1

# 12:35 Sector ETF heatmap recompute (11 SPDR sector ETFs x 7 trailing total-return

35 0 * * * cd /home/shen/fathom/backend && /home/shen/.local/bin/uv run python -m pipeline.nightly_sector_heatmap >> /home/shen/fathom/backend/logs/nightly_sector_heatmap_cron.log 2>&1

# 12:40 Market-breadth recompute (S&P 500: % above 50-/200-day SMA, net new 52-week
# highs minus lows). AFTER the 12:05 bar-cache job, which fetches all 503 constituents'
# 2y daily bars into SharedBarsCache, so this is a warm-cache read (~3-15s, zero
# incremental FMP requests). Run earlier, or after a failed 12:05 job, it
# self-heals with one live ~503-request batch (~30s-5min). Skipped while
# daily_prices is off. Raises (heartbeat failure) rather than saving a row when
# <97% of constituents have a bar. See pipeline/nightly_market_breadth.py.
40 0 * * * cd /home/shen/fathom/backend && /home/shen/.local/bin/uv run python -m pipeline.nightly_market_breadth >> /home/shen/fathom/backend/logs/nightly_market_breadth_cron.log 2>&1

# 2:45 FMP earnings/dividends/splits cache (Phase 6a) -- full-history replace per

45 2 * * * cd /home/shen/fathom/backend && /home/shen/.local/bin/uv run python -m pipeline.nightly_corporate_events >> /home/shen/fathom/backend/logs/nightly_corporate_events_cron.log 2>&1

# 2:50 Monthly Momentum snapshot (3mo/6mo/12mo composite trailing-return ranking
# over the Moat-rated universe). Moved from 3:05 on 2026-09-30 so it no longer
# lands inside the fundamentals window. Cache-only (~10-30s). Tried daily across

# the real first trading day past the 1st. The script itself
# (helpers/trading_calendar.py::resolve_month_end_anchor) checks whether today is

# 2:55 S&P 500 fundamentals refresh. Reuses the cache-aware fetch pipeline
# (get_step1_data / get_step2_data / get_step4_data / get_step5_data / get_summary);
# a cold cache does a full fetch (~7,000 FMP calls, 30-65 min), every run after

# the redirect below is only a catch-all for a crash before that log is configured.
